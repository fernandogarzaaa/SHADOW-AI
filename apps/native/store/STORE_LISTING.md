## Full description
Shadow is a local-first personal AI agent. Unlike cloud assistants, your memory
and history stay on a node you control, stored encrypted — the cloud is used only
when you explicitly approve it.

- Ask questions grounded in your own notes and memory.
- Hybrid model routing: simple questions are answered on-device; only hard ones
  use a frontier model, and only the compressed context is sent — saving tokens.
- Run real, sandboxed actions (notes, reminders, web fetch) behind an approval gate.
- Connect your own model provider (Anthropic, OpenAI, Google) with an API key.
- Full audit log and one-tap emergency pause.

Shadow requires a Shadow Node (open-source) that you run. The app connects only to
the node you configure. No analytics, no trackers, no ads.
