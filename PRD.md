# PRD: Shadow Agent

## Vision
Shadow Agent is a local-first personal AI operating layer: Siri + personal memory + autonomous Ghost agent + encrypted RAG, with explicit consent and revocable autonomy.

## Problem
Users have fragmented context across email, calendars, files, notes, messages, browsing, photos, and devices. Current assistants are reactive and lack trustworthy long-term personal memory, consent architecture, auditability, and safe action boundaries.

## Target Users
Primary: AI power users, founders, developers, operators, and professionals with high context load. Secondary: students, researchers, executive assistants, local business owners, and remote workers.

## Use Cases
Summarize unread emails, draft replies in the user's style, surface urgent work, remember preferences, answer from documents, daily briefings, task recommendations, approved desktop workflows, device connection, transparent memory review.

## MVP Scope
Production foundation for iOS command center, local encrypted memory, manual ingestion, connector architecture, agent chat, approval queue, desktop node bridge, policy engine, audit log, GHOST adapter, AXIOM adapter, documentation, and tests.

## Non-goals
No hidden keylogging, covert app monitoring, silent chat reading, microphone/camera recording, auto-send without approval, impossible privacy claims, iOS sandbox bypass, or spyware-like behavior.

## Success Metrics
Successful local setup under 15 minutes; all critical policy tests pass; every sensitive action creates approval/audit artifacts; memory deletion is verifiable; cloud escalation defaults to deny.

## Risks
App Store scrutiny, user trust, overbroad connectors, prompt injection, unsafe desktop automation, cloud leakage, and encrypted data recovery UX.

## Roadmap
v0.1 Shadow Inbox + Memory; v0.2 Shadow Learns Me; v0.3 Shadow Acts; v0.4 AXIOM compression; v0.5 Ghost autonomous desktop workflows; v1.0 App Store-ready release.
