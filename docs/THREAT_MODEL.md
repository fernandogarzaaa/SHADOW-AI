# Threat Model
Threats: malicious connectors, prompt injection, stolen node, replayed pairing challenge, revoked device reuse, cloud oversharing, unsafe desktop automation, destructive action mistakes, and audit tampering.

Mitigations: explicit consent, durable encrypted stores, pairing signatures/nonces/expiration/key pinning/revocation, cloud default-deny, AXIOM redaction, approval gates, critical double confirmation, emergency pause, safe mock Ghost executor, and append-only audit repository semantics.
