# IOS APP

The beta iOS structure includes a real `ShadowAgentApp` target placeholder under `ShadowAgent.xcodeproj`, app icon and launch screen placeholders, environment configuration, API base URL settings, Keychain-backed secret-store seam, local mock mode, real node mode, and navigation to Home, Ask Shadow, Memory, Memory Detail, Approvals, Approval Detail, Devices, Pair Device, Audit Log, Privacy Dashboard, Autonomy Settings, Connector Settings, Model Provider Settings, and Emergency Pause.
